Hero background video
---------------------
hero.mp4 here is an original brand-motion loop (12 s, 1280x720, ~650 KB) generated by tools/make-hero-video.mjs.
To use your own footage, replace hero.mp4 (and optionally add hero.webm) and ../img/hero-poster.jpg, then run npm run build.

Guidance: 1920x1080, 8-15 s seamless loop, no audio, under ~4 MB (H.264). Use footage you own or have licensed.
Regenerate the brand loop:  cd tools && npm install && node make-hero-video.mjs
